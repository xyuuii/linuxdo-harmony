# 官方 App 布局参考与鸿蒙适配

参考来源：[LINUX DO Community 的 App Store 页面](https://apps.apple.com/us/app/linux-do-community/id6758321192)，观察日期 2026-10-12。放大检查首页、帖子阅读浅色/深色、通知、搜索、个人页截图。截图只证明所示布局，未把未展示的菜单、动画或聊天行为当成已经观察到的事实。

## 页面结构

| 页面 | 官方截图中可见的结构 | 本项目采用方式 |
| --- | --- | --- |
| 首页 | 紧凑品牌栏；内容分段筛选；标题优先的连续列表；分类、标签、头像、回复与时间同排 | 保留真实数据与置顶展开；内容筛选绑定 Discourse 列表接口；玻璃与触摸高光复用鸿蒙现有组件 |
| 帖子详情 | 大标题在作者前；分类及回复数；轻标签；作者与时间/楼层分列；连续正文；回复与楼层进度在底部 | 调整首楼层级，使用真实话题元数据；保留原生富文本、大图、楼中楼与半屏回复；楼层入口显示数值 |
| 深色阅读 | 统一深底、柔和分隔、代码区域稍提亮，正文与辅助信息区分明确 | 使用现有浅/深色资源，保留高对比和减少动态设置，不硬编码 iOS 颜色 |
| 搜索 | 紧凑标题、搜索框、筛选/排序、结果概览、标题与摘要的连续结果 | 使用现有话题搜索与六种排序；不展示没有接入服务的用户/分类搜索标签 |
| 个人页 | 身份区、快捷入口、分组菜单，减少大标题与重复说明 | 复用总结、私信、活动、喜欢、通知、资料、设置与诊断；不伪造统计、收藏数或草稿数 |

## 适配边界

页面信息结构参考官方截图，材质和交互继续采用 HarmonyOS：ReaderGlassSurface、系统符号、触点流光、导航自动收拢、透明系统栏避让，以及半屏回复。按用户后续明确要求，底栏对齐官方五入口“话题 / 分类 / 搜索 / 消息 / 我的”；消息独立承载通知，铃铛和个人页入口也转入该主标签。首页可切换多类话题，双击话题入口回顶刷新仍可用。

用户进一步选择手机IT之家的顶部样式：品牌/搜索/通知行与固定文字标签，选中加粗、短下划线，取消顶部整条胶囊。左右滑动只切首页内容筛选，根主页面不响应横滑；内容使用原生Swiper，五页独立缓存并预取邻页，手指拖动过程中可见第二页内容，不在松手后清空同一列表。原生横向分页与纵向List/Refresh使用系统手势识别，移除手写Pan。底部五入口仍通过点击切换。玻璃控件统一移除投影、降低染色/模糊，参考实际Pura X View上的酷安7.1.1和IT之家9.01。

用户随后明确首页右上角应为官方iOS的发帖入口，已替换为原生铅笔图标并接入新建话题。未登录先完成登录再续开；新建编辑器采用接近全屏的原生Sheet，提供标题、真实可发分类、标签和正文，回复继续默认50%。参考真机IT之家9.01编辑器，将关闭、标题、发布合并为一行；统一画布底色，移除拖动白条、副标题及输入卡片堆叠。标题等元信息与正文放入可滚动表单，图标工具栏固定在键盘上方。成功回执关闭面板后进入新话题，审核排队只提示等待审核；结果未知保留草稿并避免自动重试。消息只保留在底栏及个人页入口。

首页的“浏览分类”进入已有分类目录，不能伪装成尚未接入的下拉过滤器。帖子工具不添加没有真实行为的收藏、分享或搜索按钮。对照时区分 iPhone 与鸿蒙字体/屏幕密度，以及演示数据与当前论坛数据造成的换行差异；不以截图里的示例内容代替真实帖子。
