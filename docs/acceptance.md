## 本次修复

- GitHub 认证导航被论坛域名限制拦截，改为精确的身份提供方主机名单。
- Discourse 系统用户 id=-1 映射失败；用户支持合法非零整数，话题/帖子/分类仍要求正整数。
- 分类请求补全父 slug，避免 canonical 跳转；SDK 2300047 正确提示网页验证，写请求不重放。
- 首楼恢复标题，小图标按语义行内显示；拆开楼层和原图 sheet。
- 从末尾返回首楼重新拉取首批内容，区分楼层号与总条数。
- 移除分类详情不适用的104vp页签预留，收紧首页/分类/搜索布局。

## 0.2.0 帖子阅读重排

以手机贴吧官方截图的阅读层级为参考，采用作者/楼主标记→主楼标题正文→大图→连续回复→浅底楼中楼，底部固定回复入口与楼层导航。没有增加虚构的贴吧等级、关注或分享数据，仍使用真实Discourse权限。喜欢直接点按，其他回应长按；简评默认三条预览，更多操作按权限收纳。

正文图根据原图宽高满宽布局，长图顶部大预览明确提示查看完整图片；原图以全屏黑底显示。真实2998703帖的4张图片已实测1/4→2/4左右切换；双击放大和平移时保持当前图片，系统返回后图前文字和图片框的像素位置一致。横图的双击放大、关闭返回和主楼位置保持也已观察。系统SaveButton与账号/Cookie隔离仍按原机制。双指与边界几何有7项回归，未在物理设备测试多指手势或功耗。

现场修复了LazyForEach稳定key下楼中楼收起后展开入口不更新的问题：使用复用的ObservedV2行对象更新Trace属性，维持子组件key和本地简评输入状态。模拟器已复验收起后的展开入口出现，点按后两条子回复重新显示；底部回复入口进入编辑器，空内容的发表按钮保持禁用。64项本地回归通过，完整SDK构建、签名、安装和启动通过；本次查询未发现该包的崩溃日志。详细交互说明见post-reading-design.md。
