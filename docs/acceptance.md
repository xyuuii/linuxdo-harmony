## 2026-10-18 会话恢复与连接能力验证（本地调试版）

沿用 ArkWeb Cookie 存储和现有网络适配器，新增只读请求的共享恢复流程：遇网页验证时限时打开同源首页，等待同源顶层文档可执行，通过实际 `/session/csrf.json` 的 200 / JSON / 非挑战回执确认可用，最多探测三次；单次恢复上限 15 秒，恢复之间至少间隔 30 秒。成功后读取最多重试一次，迟到的旧挑战可复用另一请求已恢复的上下文。同站图片共用恢复，外域图片不会触发论坛验证。普通 401、权限 403、429、5xx 与未知写入结果不会触发自动重放。

正在提交的写请求会阻止恢复导航；新请求等待已有恢复结束。发帖、喜欢、上传等写请求不自动重放，CSRF 读取可以在写入前恢复。切后台、换账号、进入手动登录、组件销毁会取消恢复，取消单个读取不影响其他共享消费者。原生响应轮换或撤销 `_t`、`_forum_session`、`cf_clearance` 时请求及时落盘，缩小 ArkWeb 默认周期落盘前退出应用的窗口；落盘失败不改变已收到的成功写入回执。不备份或回灌旧过盾 Cookie，不复制 Android 项目源码或闭源 SDK。

新增“我的 → 关于与连接诊断 → 检测连接能力”：分别检测系统 DNS、阿里公共 DoH 和 Cloudflare 对照站点。原生探测不附带论坛 Cookie，网页使用独立隐私模式，不注册原生桥；只输出经过 host/TLS/SNI 校验的连接摘要，不保留 trace 中的 IP 等字段。完成、退出或隐藏页面后撤销进程内临时 DoH，未修改系统 DNS，也未开启日常请求的直连模式。

验证：243 项离线回归全部通过，包括并发恢复、超时释放、取消与账号代际、写入不重放、凭据轮换落盘、图片边界、探测脱敏和 DNS 清理；API26 SDK 编译及调试签名通过，保留数据安装 CodexPhone 成功。模拟器重新启动后读取到既有登录账号，未重新输入凭据。连接页已核对原生界面与截图；未向论坛发帖、点赞、上传或删除。

当前网络下，社区原生请求在系统 DNS 与 DoH 下均返回 TLSv1.3、`sni=plaintext`；社区隐私网页没有有效握手回执，对照站点也未取得可用于确认 ECH 的回执。因此本轮没有证明 ArkWeb 不支持 ECH，也没有证明国内免代理可用；不能把 DoH 配置成功当作已实现加密 SNI。真实手机、运营商网络和 clearance 长期过期恢复仍待验证。只有模拟器在线，本轮没有真机安装或外部发布。
