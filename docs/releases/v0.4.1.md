# 0.4.1 · 阅读重排、四类目录与个人记录

这次更新主要整理阅读界面，并补齐找帖、目录和个人内容的常用入口。

- **阅读**：昵称与用户名分层；简评紧跟正文；多段引用合并显示；回复、收藏和楼层进度集中在底部胶囊。
- **找帖**：分类、标签、排序和排行时段筛选；最近搜索、常用高级筛选及话题内搜索。
- **目录**：分类、标签、徽章、群组四个入口；分类查找与子分类展开，标签排序及话题跳转。
- **个人内容**：收藏、本机草稿和参与记录；增加投票、方案与 Boost 记录入口，以及只读用户资料页。
- **编辑与操作**：主动预览、按权限查看编辑历史、引用回复、分享、举报及话题通知设置。
- **阅读偏好**：默认话题列表、沉浸话题和打开首个未读。

## 下载与安装

需要 **HarmonyOS 7 / API 26**。附件提供普通 HAP、edge DoH/ECH 试验 HAP、`SHA256SUMS` 和第三方许可原文。

两个 HAP 同包名，覆盖切换，不能并装；均为开发调试签名包，安装受签名设备授权限制。其他设备请使用自己的开发者签名构建，不能将本附件理解为任意设备均可直接安装的商店包。

普通版不默认开启试验 DoH/ECH。edge 版仍属联网试验，不保证所有网络直连或长期免验证，用户仍可能需要完成站点验证。[试验说明](https://github.com/xyuuii/linuxdo-harmony/blob/v0.4.1/experiments/ech-probe/README.md)
