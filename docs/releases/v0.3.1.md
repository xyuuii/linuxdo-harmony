# 0.3.1 · 图片、紧凑导航与 ECH 试验包

修复图片、表情和会话恢复，并调整底栏尺寸与光感。

- 修复论坛与已验证 CDN 图片读取、GIF/WebP 动态头像、回应表情映射，以及小图/表情被放大的问题。
- 统一楼中楼与正常回复的主题底色。
- 只读会话恢复等待可用的同源新文档及有效 JSON CSRF 回执，使用共享 25 秒预算；连接重置最多重连一次，写请求不自动重放。
- 文字可从上下栏后透出，底栏在原生 TabBar 宿主中保留触点光感，去掉叠层背板、投影及单项圆形选中底。
- 主导航最大 280×52vp 居中，收起为 48vp 圆，保留五入口、未读角标、双击回顶及握姿侧别布局。

## 下载与安装

需要 **HarmonyOS 7 / API 26**。附件均为开发调试签名 HAP，受签名设备授权限制，**不是任意设备通用安装包**；其他设备需按 [构建说明](https://github.com/xyuuii/linuxdo-harmony/tree/v0.3.1#工程与构建)使用自己的开发者签名。尚未上架应用市场。

| 文件 | 用途 |
| --- | --- |
| `LinuxDo-HarmonyOS7-0.3.1-debug.hap` | 普通版，包含共同修复，不默认启用试验 DoH/ECH |
| `LinuxDo-HarmonyOS7-0.3.1-edge-ech-trial-debug.hap` | edge DoH/ECH 试验版，延续本轮真机测试方案 |
| `SHA256SUMS` | 附件校验值，下载后可用 `shasum -a 256 -c SHA256SUMS` 核对 |
| `ECH-THIRD-PARTY-LICENSES.txt` | 试验包原生依赖许可与归属原文，同时内嵌于试验 HAP |

两包同包名，覆盖切换而不并装；无需为切换卸载或清数据。试验版业务请求与图片在有效 CSRF 回执后使用 ArkWeb，Rustls 原生库用于连接诊断，不能理解为所有操作均由 Rustls 传输。

## 验证范围

306 项离线逻辑测试及 API26 SDK 编译、调试签名通过。图片、动头像、正文读取、上下栏文字透底、触点提亮、五入口及收放/回顶有 Pura X View 与 CodexPhone 记录，见 [验收记录](https://github.com/xyuuii/linuxdo-harmony/blob/v0.3.1/docs/acceptance.md)。新版本号及打包复核不作为一次新的真机网络验证。

ECH 在 2026-10-19/20 的真机 Wi-Fi/5G 条件下取得过加密 SNI、读取、图片及进程重启恢复证据；第三方解析服务与网络环境会变化。这是预览试验包，不承诺全网免代理、永不掉盾或自动处理验证码；新登录、上传、所有写操作及长期验证过期恢复未完整验收。详见 [实验说明](https://github.com/xyuuii/linuxdo-harmony/blob/v0.3.1/experiments/ech-probe/README.md)。详细媒体诊断默认关闭，发布包仅保留安全的启动/状态分类日志。

第三方社区客户端，非 LINUX DO 官方出品。感谢 [LINUX DO 社区](https://linux.do/)、[@xmk2025 的原帖](https://linux.do/t/topic/2998703)及 [xuemk/linuxdo-android](https://github.com/xuemk/linuxdo-android) 提供功能与接口行为参考；许可边界见 [THIRD_PARTY.md](https://github.com/xyuuii/linuxdo-harmony/blob/v0.3.1/THIRD_PARTY.md)。
